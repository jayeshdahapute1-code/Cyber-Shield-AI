# CyberShield AI

Mobile cybersecurity prototype with a cyberpunk UI.

## Build on GitHub from a phone
1. Upload the complete project to the `CyberShieldAI` repository.
2. Open **Actions** → **Build CyberShield AI APK**.
3. Tap **Run workflow** (or push to `main` to start automatically).
4. When complete, open the workflow run → **Artifacts** → `CyberShieldAI-debug-apk` and download the APK.

This prototype is a UI/demo security app. Real malware detection, email/message access, and APK interception require additional Android APIs, permissions, and backend/security engines.
